1Why this matters

A real Growth & Decay problem — and the gap in your toolkit it exposes.

You invest $1000 in a long-term fund that, historically, doubles in value about every 7 years. You'd like to know when your investment passes $1 000 000.

Each doubling multiplies the balance by 2, so after n doublings you have 1000 × 2n dollars. Reaching a million means solving:

2n = 1000

From the warm-up you can already feel the problem: 29 = 512 and 210 = 1024. The answer sits somewhere between 9 and 10 doublings — but inspection can't tell you exactly where.

This is the job of a logarithm. The logarithm log2(1000) means precisely "the power of 2 that gives 1000" — and a calculator returns log2(1000) ≈ 9.97 doublings (about 70 years).

Today: what a logarithm is, and how every exponential fact can be read as a logarithmic fact — the same statement, two ways round.

3Explicit teaching — the definition

A logarithm is an exponent in disguise. Here is the precise definition, how to convert between forms, and the two calculator buttons you'll meet.

The definition
loga(x) = y   means exactly the same as   ay = x
where a > 0,   a ≠ 1,   and   x > 0

Read a logarithm out loud as a question: "a to the what power gives x?" — and the answer to that question is y.

The same fact, two ways round

An exponential statement and a logarithmic statement carry identical information. Notice how the base and the exponent match across both forms:

23 = 8
base · exponent · result
⇔
log2(8) = 3
base · argument · the log equals

Converting between the two forms

To convert exponential → logarithmic: the base stays the base, the result moves inside the brackets to become the argument, and the exponent becomes what the logarithm equals. To convert logarithmic → exponential, run the same swap in reverse.

34 = 81   ⇔   log3(81) = 4

Two buttons on your calculator

For "nice" numbers you can find a logarithm by inspection. When the numbers aren't nice, your calculator has two logarithm buttons:

log
Common logarithm — base 10. When a logarithm is written with no base shown, base 10 is assumed. So log(1000) means log10(1000) = 3.
ln
Natural logarithm — base e (≈ 2.718). Same operation as log, just a different base. e is a special constant you'll work with in detail in Stage 2.
💡 About "ln" for now: all you need today is that the ln button exists and uses base e ≈ 2.718. It behaves exactly like the log button — same idea, different base. You'll use it properly in Stage 2.

Why the argument must be positive

A positive base raised to any power — positive, negative, or zero — always gives a positive result (for example 2−3 = 18, still positive). Since loga(x) asks "what power gives x?", and no power of a positive base is ever zero or negative, the argument x must be positive. That is why log(0) and log(−5) have no answer.

⚠️ Common mistakes to avoid:
  • Mixing up base and result. In log2(8), the base is 2 and 8 is the result — don't swap them.
  • Reading it as multiplication. log2(8) is not "2 lots of 8". It is a single operation: the power.
  • Taking the log of 0 or a negative number. log(0) and log(−7) are undefined.

5Worked Example 1 — converting between forms

Worked Example 1 (a) Write 34 = 81 in logarithmic form.   (b) Write log5(125) = 3 in exponential form.
1
Identify the parts
For part (a), label the base, the exponent, and the result.
34 = 81  →  base = 3,   exponent = 4,   result = 81
2
Apply the definition
Use ay = x ⇔ loga(x) = y. Base stays the base; the result becomes the argument; the exponent becomes what the log equals.
34 = 81  ⇔  log3(81) = 4
3
Reverse the swap for part (b)
log5(125) = 3 has base 5, argument 125, and the log equals 3. So ay = x gives 53 = 125. Check: 5 × 5 × 5 = 125. ✔
log5(125) = 3  ⇔  53 = 125
Answer 34 = 81 ⇔ log3(81) = 4   |   log5(125) = 3 ⇔ 53 = 125

7Worked Example 3 — using the calculator

Worked Example 3 · we do Use a calculator to evaluate, correct to 3 decimal places: log10(7),   ln(7),   ln(20).
1
log10(7) — use the log button
The log button is base 10, so no base needs to be entered. Press log, then type 7.
log10(7) = 0.845  (3 d.p.)
2
ln(7) — use the ln button
"ln" is the natural logarithm: base e ≈ 2.718. Press ln, then type 7.
ln(7) = 1.946  (3 d.p.)
3
ln(20) — and compare
Same ln button. Then notice: log10(7) ≈ 0.845 but ln(7) ≈ 1.946 — the same number 7, but different answers, because the base differs (10 versus e).
ln(20) = 2.996  (3 d.p.)
Remember log button → base 10  ·  ln button → base e ≈ 2.718
