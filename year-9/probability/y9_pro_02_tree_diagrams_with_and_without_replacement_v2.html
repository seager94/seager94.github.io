1Why this matters

A real situation that is secretly today's probability.

A café runs a lucky draw. A jar holds 3 gold and 7 silver tokens. Each customer draws two tokens and wins a $20 voucher if both are gold.

The owner must budget for the vouchers. But should the first token go back in the jar before the second draw, or stay out? That one decision changes the chance of winning, and so the cost per 300 customers.

A tree diagram shows each step of a compound event as a set of branches. Today you multiply along a path to find the probability of one outcome, and add across paths for an event that can happen more than one way. Without replacement, the second set of branches changes.

5Worked example — the 3-step method

A bag holds 3 red and 2 blue counters. Two counters are drawn without replacement. Find P(one red and one blue).

1
Draw the tree and label every branch
First draw: 3 of 5 are red. If a red is taken out, 4 counters are left and only 2 are red. If a blue is taken out, 4 are left and 3 are red.
Each set of branches from one point adds to 1: 24 + 24 = 1 and 34 + 14 = 1
2
Multiply along each path
Each path is one outcome. Multiply the branch probabilities along it.
P(R, B) = 35 × 24 = 620   Check: 6 + 6 + 6 + 2 = 20, so the paths add to 1.
3
Add the paths that give the event
One of each colour happens two ways: red then blue, or blue then red.
P(one of each) = 620 + 620 = 1220 = 35
