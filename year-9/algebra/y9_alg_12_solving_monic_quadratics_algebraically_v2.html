1Why this matters

A real situation that's secretly today's algebra.

A diver leaps from a 5 m platform. Her height above the pool, t seconds after she jumps, is modelled by:

h = −t2 + 4t + 5

The coach wants to know when she hits the water. That means finding the value of t for which h = 0 — the moment her height above the pool is zero.

Setting h = 0 gives a quadratic equation. Today's job is to solve equations like this — to find the values of the variable that make them true. Those values are also the x-intercepts of the parabola you'd see on a graph.

2Key vocabulary

Tap each card to flip it. These five words sit at the heart of today's method.

Quadratic equation
Tap to flip
An equation containing an x2 term (and no higher power).
x2 + 5x + 6 = 0 is a quadratic equation.
Monic
Tap to flip
A quadratic where the coefficient of x2 is 1.
x2 − 7x + 12 is monic. 3x2 − 7x + 12 is not.
Root (solution)
Tap to flip
A value of x that makes the equation true. A monic quadratic usually has two roots.
The roots of x2 − 9 = 0 are x = 3 and x = −3.
Factorise
Tap to flip
Rewrite as a product of two brackets. For monic quadratics, find two numbers that multiply to c and add to b.
x2 + 5x + 6 = (x + 2)(x + 3).
Null factor law
Tap to flip
If A × B = 0, then A = 0 or B = 0. That's the only way a product can be zero.
If (x + 2)(x + 3) = 0, then x + 2 = 0 or x + 3 = 0.

5The method: 4 worked examples

Step 1. Rearrange so one side is zero.   Step 2. Factorise the quadratic.   Step 3. Apply the null factor law to read off the two roots. The roots are exactly the x-intercepts of the parabola.

Example ASolve x2 + 5x + 6 = 0

= 0?Yes — already equals zero.
Factorise(x + 2)(x + 3) = 0
Two numbers: × to +6, + to +5 → 2 and 3.
Null factorx + 2 = 0  or  x + 3 = 0
State rootsx = −2  or  x = −3
Two rootsx = −2,  x = −3
The parabola y = x2 + 5x + 6 crosses the x-axis at −2 and −3 — the two roots.

Example BSolve x2 − 7x + 12 = 0

= 0?Yes — already equals zero.
Factorise(x − 3)(x − 4) = 0
× to +12, + to −7 → both numbers are negative: −3 and −4.
Null factorx − 3 = 0  or  x − 4 = 0
State rootsx = 3  or  x = 4
Two rootsx = 3,  x = 4
The parabola y = x2 − 7x + 12 crosses the x-axis at 3 and 4.

Example CSolve x2 + x − 12 = 0

= 0?Yes — already equals zero.
Factorise(x + 4)(x − 3) = 0
× to −12, + to +1 → opposite signs: +4 and −3.
Null factorx + 4 = 0  or  x − 3 = 0
State rootsx = −4  or  x = 3
Two rootsx = −4,  x = 3
The parabola y = x2 + x − 12 crosses the x-axis at −4 and 3.

Example D · specialSolve x2 − 9 = 0

= 0?Yes — already equals zero.
Factorise(x + 3)(x − 3) = 0
Difference of two squares: a2 − b2 = (a + b)(a − b). Here b = 3.
Null factorx + 3 = 0  or  x − 3 = 0
State rootsx = −3  or  x = 3
Two rootsx = −3,  x = 3
The parabola y = x2 − 9 crosses the x-axis at −3 and 3 — symmetrical about the y-axis.

⚠ Two errors this lesson hinges on

  • Failing to set the equation to zero before factorising. If you try to factorise x2 + 5x = −6 as it stands, the null factor law doesn't apply — only a product equal to zero forces a factor to be zero. Always rearrange first so one side is zero.
  • Dropping the second root. A monic quadratic has two solutions. Writing only x = 3 when the equation is x2 − 9 = 0 loses half the answer. Always state both roots — they're both x-intercepts of the parabola.

6Order the steps

Below are the four steps for solving the equation in the box — but they're in the wrong order. Discuss with your neighbour, then drag them into the correct sequence using the ↑ and ↓ buttons. Click Check order when you're ready.

Solve: x2 − 5x + 6 = 0
  • Apply the null factor law:  x − 2 = 0  or  x − 3 = 0
  • Check the equation equals zero.  x2 − 5x + 6 = 0 ✓ (already in the right form)
  • State the two roots:  x = 2  or  x = 3
  • Factorise:  (x − 2)(x − 3) = 0   (× to +6, + to −5)
💡 Why the order matters: you can't apply the null factor law until the equation is factorised, and you can't factorise reliably until everything is on one side equal to zero. Each step unlocks the next.
