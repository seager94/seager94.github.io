1Why this matters — ramps, escalators and skate parks

Steepness has rules. Every ramp around you is the result of someone calculating a gradient.

Look around any public building. The wheelchair ramp at the front is not random — Australian Standard AS 1428.1 says the gradient cannot be steeper than 1 in 14 (a rise of 1 metre over a run of 14 metres). Steeper than that and a wheelchair user can't push themselves up safely.

  • 🛗 Escalators sit at about 1 in 1.7 (≈ 30°).
  • 🛹 A "mellow" skate ramp runs around 1 in 8; a vert ramp is nearly vertical.
  • 🛣 Australian road signs warn drivers when the gradient is steeper than 1 in 10 (10%).
Each of those numbers is a gradient — the rise (vertical change) divided by the run (horizontal change). Today we'll calculate the gradient of a line segment between any two points on the Cartesian plane, and we'll see how a single number tells us whether the line is gentle, steep, flat, uphill or downhill.

5Worked example — the 3-step method

Find the gradient of the line segment from A(1, 2) to B(4, 8).

A(1, 2) and B(4, 8). The dashed lines form a right triangle: run = 3, rise = 6.
1
Identify rise and run
Label the two points and find how far you go across (run) and up (rise).
A = (1, 2)    B = (4, 8)
run = x₂ − x₁ = 4 − 1 = 3
rise = y₂ − y₁ = 8 − 2 = 6
2
Apply the gradient formula
Gradient = riserun
gradient = riserun = 63 = 2
3
Interpret the answer
A gradient of 2 means: for every 1 step right, the segment rises 2 steps up. Positive gradient → uphill from left to right.
For each unit you move right, the line goes 2 units up. Steeper than a 1-in-2 ramp.
Answer gradient = 2

5Three more types of gradient

Same method, different segments. Watch what the gradient number tells you each time.

Example A — Downhill (negative gradient)

Find the gradient from C(1, 6) to D(5, 2).

From C to D: across 4, down 4. The rise is negative because we drop.
run = 5 − 1 = 4  ·  rise = 2 − 6 = −4
gradient = −44 = −1   → downhill, one step down for every step right.

Example B — Horizontal (zero gradient)

Find the gradient from E(1, 4) to F(7, 4).

Both points have y = 4. There is no rise to draw — the triangle collapses.
run = 7 − 1 = 6  ·  rise = 4 − 4 = 0
gradient = 06 = 0   → horizontal segment. Zero rise, zero steepness.

Example C — Steep vs shallow

Two segments both start at P(1, 1). Segment PQ goes to Q(3, 7); segment PR goes to R(7, 4). Which is steeper?

Same starting point. PQ rises fast over a short run; PR rises slowly over a long run.
PQ: rise = 6, run = 2 → gradient = 62 = 3
PR: rise = 3, run = 6 → gradient = 36 = 12
3 > 12   → PQ is the steeper segment (six times steeper, in fact).
