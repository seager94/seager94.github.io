1Why this matters

A real situation that's secretly today's algebra.

A landscaper is designing a square garden of side length x metres and wants to add a 3-metre path along one edge and a 5-metre path along the adjacent edge.

The new rectangle has dimensions (x + 3) by (x + 5).

How do you find its total area? You can't just say "x + 3 times x + 5 = x2 + 15" — that ignores the cross-strips. Today we learn the method that gets it right.

Splitting the rectangle into four smaller sections shows that the total area is made up of four partial products. This is exactly what expanding two brackets means — finding the area of each part and adding them all up.

This idea — area = product of dimensions — is why expanding binomials always produces four terms before simplification.

2Key vocabulary

Tap each card to flip it. You will use these five words throughout today's lesson.

Binomial
Tap to flip
An algebraic expression with exactly two terms, joined by + or −.
x + 3 and 2x − 5 are binomials. x2 + 3x + 1 has three terms so it is a trinomial.
Expanding
Tap to flip
Removing brackets by multiplying every term in the first bracket by every term in the second.
(x + 2)(x + 3) → x2 + 5x + 6
Partial product
Tap to flip
One of the four individual products formed when expanding two brackets. They are added together to get the full expansion.
In (x+3)(x+5) the four partial products are x2, 5x, 3x, 15.
FOIL
Tap to flip
A mnemonic for the four pairs: First, Outer, Inner, Last. Each letter names one partial product.
(a+b)(c+d): F=ac, O=ad, I=bc, L=bd → ac+ad+bc+bd
Quadratic expression
Tap to flip
An expression where the highest power of the variable is 2. Expanding two linear binomials always produces one.
x2 + 8x + 15 is quadratic. The leading term is x2.

5Worked example 1 — (x + 3)(x + 5)

Both brackets have positive terms. We expand by finding the area of each sub-rectangle.

1
Set up the area model
Draw a rectangle with width (x + 3) and height (x + 5). Split each dimension to get four sub-rectangles.
Each cell = one partial product
Reading the area model:
(x + 3)(x + 5)
= x · x + x · 5 + 3 · x + 3 · 5
   F         O         I         L
2
Calculate each partial product
Write out each product, then add them in order.
= x2 + 5x + 3x + 15
3
Collect like terms
The Outer and Inner terms (x-terms) are like terms. Combine them.
= x2 + (5 + 3)x + 15
= x2 + 8x + 15
Answer(x + 3)(x + 5) = x2 + 8x + 15

6Worked example 2 — (x + 7)(x − 8)

One bracket has a negative term. Watch how the negative sign flows through into two negative partial products.

1
Set up the area model — note the negative column
Red cells = negative partial products
Applying FOIL:
(x + 7)(x − 8)
= x · x + x · (−8) + 7 · x + 7 · (−8)
2
Write the four partial products
= x2 − 8x + 7x − 56
3
Collect like terms: −8x + 7x = −x
= x2 + (−8 + 7)x − 56
= x2 − x − 56
Answer(x + 7)(x − 8) = x2 − x − 56

7Worked example 3 — (x − 4)(x − 6)

Both brackets have negative terms. Watch how negative × negative gives a positive Last product.

1
Set up the area model — two negative dimensions
(−4)(−6) = +24 — negative × negative = positive
Key insight: the Last product is positive because negative × negative = positive.
(x − 4)(x − 6)
= x·x + x·(−6) + (−4)·x + (−4)·(−6)
2
Write the four partial products
= x2 − 6x − 4x + 24
3
Collect like terms: −6x − 4x = −10x
= x2 + (−6 − 4)x + 24
= x2 − 10x + 24
Answer(x − 4)(x − 6) = x2 − 10x + 24

8Worked example 4 — (2x + 1)(x + 3)

Now the first bracket has a leading coefficient of 2. The First product becomes 2x2 — the method is identical.

1
Set up the area model — note the 2x row
First product: 2x × x = 2x²
Applying FOIL:
(2x + 1)(x + 3)
= 2x·x + 2x·3 + 1·x + 1·3
2
Write the four partial products
= 2x2 + 6x + x + 3
3
Collect like terms: 6x + x = 7x
= 2x2 + (6 + 1)x + 3
= 2x2 + 7x + 3
Answer(2x + 1)(x + 3) = 2x2 + 7x + 3
