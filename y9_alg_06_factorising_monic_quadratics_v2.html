1Why this matters

Factorising shows up wherever a quadratic models a real situation.

A landscape architect is designing a rectangular garden bed. The area (in square metres) is modelled by the expression x2 + 7x + 12, where x is a design parameter.

To work out the length and width, they need to rewrite this quadratic as a product of two linear factors — that is, they need to factorise it.

They discover the dimensions are (x + 3) m and (x + 4) m — because (x + 3)(x + 4) = x2 + 7x + 12.

Factorising is the reverse of expanding. Expanding goes right: multiply out the brackets to get a quadratic.

Factorising goes left: start with the quadratic and find the brackets that produce it.

(x + 3)(x + 4)  ⟷  x2 + 7x + 12

Every answer you write today can be self-checked by expanding back — if you land on the original quadratic, you're right.

5Worked example — x2 + 7x + 12

The method has three steps: identify the target pair, apply it, then verify by expanding. Click to reveal each step.

1
Identify — find two numbers that multiply to c and add to b
Here b = 7 (x-coefficient) and c = 12 (constant). Since both are positive, both numbers are positive.
Target: multiply to 12  and  add to 7
Factor pairs of 12:
  1 × 12 = 12,  1 + 12 = 13  ✗
  2 × 6  = 12,  2 + 6  = 8   ✗
  3 × 4  = 12,  3 + 4  = 7   ✓
2
Apply — write the two bracket factors
Place one number in each bracket: (x + 3)(x + 4).
x2 + 7x + 12  =  (x + 3)(x + 4)
3
Verify — expand back to check
Always expand your answer to confirm it matches the original. If it does, you're done.
(x + 3)(x + 4)
= x2 + 4x + 3x + 12
= x2 + 7x + 12  ✓

6Sign rules and two more patterns

The three cases below cover every monic quadratic. Read each card, then study the worked examples.

Case 1 — Both positive

b > 0 and c > 0
Both numbers are positive.
Search for p, q > 0 where pq = c and p + q = b.

Case 2 — Both negative

b < 0 and c > 0
Both numbers are negative.
Their product is positive; their sum is negative.

Case 3 — Mixed signs

c < 0 (regardless of b)
One number is positive, one negative.
The sign of b tells you which is larger in size.
Example 2: x2 − 5x + 6
1
Identify
b = −5,  c = 6
c > 0 and b < 0 → both numbers negative
Pairs of 6:  1×6 (sum −7 ✗)  ·  2×3 (sum −5 ✓)
Numbers: −2 and −3
2
Apply
x2 − 5x + 6 = (x − 2)(x − 3)
3
Verify
(x−2)(x−3) = x2−3x−2x+6 = x2−5x+6 ✓
Example 3: x2 + 2x − 15
1
Identify
b = +2,  c = −15
c < 0 → mixed signs; b > 0 → larger number is positive
Pairs of 15:  1×15 (diff 14 ✗)  3×5 (diff 2 ✓)
Numbers: −3 and +5  (−3×5=−15, −3+5=+2 ✓)
2
Apply
x2 + 2x − 15 = (x − 3)(x + 5)
3
Verify
(x−3)(x+5) = x2+5x−3x−15 = x2+2x−15 ✓
💡 Mixed-signs shortcut: the difference of the two factor sizes equals |b|. The larger factor takes the sign of b. For x² + 2x − 15: difference = 2, so the pair is 5 and 3; b > 0 so 5 is positive → −3 and +5.
