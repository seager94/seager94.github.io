1Why this matters

A real machine that's secretly doing today's geometry.

A recycling plant has one job: send every item to the right bin. The machine can't "just know" what each item is — so it runs every item past a fixed sequence of sensors:

  • Is it metal? → metal bin
  • Not metal — is it glass? → glass bin
  • Not glass — is it paper? → paper bin

Each yes/no question is a decision, and the order never changes. Run the same item twice and you always get the same bin.

Classifying a shape works exactly the same way. To name a triangle or a quadrilateral you ask a fixed sequence of attribute questions — "Are all the sides equal?", "Is there a right angle?" — and each decision sends you down one path. A set of steps and decisions like this is an algorithm. Today you'll follow, design and describe algorithms that classify shapes.

Example 2 — design a triangle algorithm (angles)
Design an algorithm that classifies any triangle by its angles as acute, right or obtuse.
1
Choose the attribute to test
Side lengths tell us nothing about angles — we must test a different attribute.
Attribute to test: the largest angle.   Possible outputs: acute, right, obtuse.
2
Put the decisions in a sensible sequence
Two decisions are enough to separate three outputs.
Decision 1 — largest angle = 90°?  YES → Right
Decision 2 (if NO) — largest angle > 90°?  YES → Obtuse,  NO → Acute
3
Test the algorithm before trusting it
Run a triangle through it to check the path works.
Angles 30°, 50°, 100° → largest = 100°.  D1: 100 = 90? NO.  D2: 100 > 90? YES → Obtuse. ✓
Output A 2-decision algorithm — see the flow chart below
The finished algorithm, drawn as a flow chart.
