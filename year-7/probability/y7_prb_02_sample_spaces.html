1Why this matters

A real situation that's secretly today's probability.

The Year 7 fundraiser has a lucky dip barrel. Inside are tickets numbered 1 to 50 — pull one out and you might win the prize.

Before Maya hands over her gold coin, she wants to know her chances. Her friend just shrugs: "you might get any number." But which numbers, exactly? To work out a probability, Maya first needs the full list of everything that could possibly happen.

That full list — every possible outcome of an event — is called the sample space. For the barrel it is the numbers 1, 2, 3, … all the way to 50. Once you can list the sample space, a probability is easy: it's the number of winning tickets out of the total in the sample space. Today we practise listing sample spaces for coins, dice, spinners and lucky dips.

Event

Flipping a coin, rolling a die, or taking a ticket from a lucky dip.
Outcome
Tap to flip
A single possible result of an event.
When you roll a die, one outcome is landing on 5.
Sample space
Tap to flip
The complete list of every possible outcome of an event, written inside braces { }.
For a coin the sample space is { Heads, Tails }.
Single-stage event
Tap to flip
An event made of just one action or step.
Flipping a coin once is single-stage. Flipping it twice is not.
Equally likely
Tap to flip
Outcomes that each have the same chance of happening.
On a fair die, every number from 1 to 6 is equally likely.

5Worked examples — listing a sample space

Each time I use the same three steps: name the event → list every outcome → write the sample space. Reveal one step at a time.

Example 1 — Throwing a coin 🪙
1
Name the event
We throw one fair coin and look at how it lands. That is a single-stage event — one action, one result.
Event: throwing a coin once.
2
List every possible outcome
A coin has just two faces. It can land showing Heads, or showing Tails — nothing else.
Heads (H)  ·  Tails (T)
3
Write the sample space
Put every outcome inside braces { }. Both faces have the same chance, so the outcomes are equally likely.
Sample space = { H, T }
Sample space — coin { H, T } — 2 outcomes
Example 2 — Throwing a six-sided die 🎲
1
Name the event
We roll one fair six-sided die and read the number on the top face. Again — a single action.
Event: rolling a six-sided die once.
2
List every possible outcome
The faces are numbered 1 to 6. Listing them in order makes sure none is missed.
1   2   3   4   5   6
3
Write the sample space
Six outcomes, each on a fair die equally likely.
Sample space = { 1, 2, 3, 4, 5, 6 }
Sample space — die { 1, 2, 3, 4, 5, 6 } — 6 outcomes
Example 3 — Spinning a spinner 🎡
1
Name the event
We spin this spinner once. It has 4 equal sections coloured red, blue, green and yellow. The arrow lands in one section.
2
List every possible outcome
Read off each colour the arrow could point to.
Red  ·  Blue  ·  Green  ·  Yellow
3
Write the sample space
The four sections are equal in size, so the outcomes are equally likely.
Sample space = { Red, Blue, Green, Yellow }
Sample space — spinner { Red, Blue, Green, Yellow } — 4 outcomes
