1Why this matters

A real situation that's secretly today's algebra.

You're filling a swimming pool with a hose. Every minute, another 50 litres of water goes in. You jot down a table:

Minutes (x)0123
Litres (y)050100150

Every row of that table is really a pair of numbers — like (1, 50). If we plot those pairs as points on a grid, something striking happens: they line up perfectly. The grid lets you see the rule.

Today we turn a rule like y = x + 2 into a table, the table into coordinate pairs, and the coordinates into points on the Cartesian plane. When the rule is linear, the points line up — literally. That's the big idea every graph from here on builds on.

2Key vocabulary

Tap each card to flip and reveal the definition. You'll use these five words constantly today.

Cartesian plane
Tap to flip
A grid made by two number lines crossing at right angles.
Named after René Descartes. Used to plot points and graphs.
Axis (axes)
Tap to flip
The two number lines: horizontal x-axis and vertical y-axis.
Always label them, and always show the scale (1 square = ?).
Origin
Tap to flip
The point (0, 0) where the two axes meet.
Every coordinate is measured from the origin.
Coordinates
Tap to flip
A pair (x, y) giving the position of a point. x first (across), y second (up).
The point (3, 5) is 3 across, 5 up.
Linear
Tap to flip
A relationship is linear when its plotted points line up to form a straight line.
y = x + 2 is linear. y = x2 is not — its points curve.

5Worked example — plot y = x + 2

Three steps: (1) build the table, (2) read off the coordinate pairs, (3) plot them on labelled axes and look for the pattern.

1
Build the table of values
Substitute x = 0, 1, 2, 3 into the rule to find each y.
x0123
y = x + 22345
2
Read off the coordinate pairs
Each column of the table becomes one point (x, y).
(0, 2)   (1, 3)   (2, 4)   (3, 5)
3
Plot on labelled axes — and look for the pattern
Draw the x-axis horizontal and the y-axis vertical, label both, mark the scale, and place each point.
Scale: 1 square = 1 unit on both axes.
The big idea The four points line up — so y = x + 2 is a linear relationship.

Linear rule: y = x + 2

Straight line ✓

Non-linear rule: y = x2

Curves — not linear ✗
💡 How we tell: plot the points, then look. If you can lay a ruler across them all, it's linear. If they bend away from the ruler, it isn't.
