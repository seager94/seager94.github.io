1Why this matters

A real situation that's secretly today's algebra.

Imagine an AFL forward called Jada is having a huge season. Going into tonight's game, she's kicked 184 career goals. Tonight she'll kick some number of new goals — we just don't know how many yet.

How do you write her new career total when you don't know tonight's number? Mathematicians use a letter to stand in for the unknown — say, g for tonight's goals. Then her new total is just:

184 + g

The second the siren goes and Jada finishes on 5 goals, we swap g for 5 and compute: 184 + 5 = 189.

Algebra is the language of "the value isn't known yet, but the rule still works." A letter (a variable) stands in for any number we like. Today you'll learn how to write and read these expressions properly — including the special conventions mathematicians use everywhere, like writing 3x instead of 3×x. These conventions are the alphabet of all the algebra to come.

5Worked example — bridging arithmetic to algebra

Question: Why does x + x + x + x equal 4x? And what does that mean?

1
Recognise the pattern: repeated addition is multiplication
Start with arithmetic you already know. 3 + 3 + 3 + 3 means we add 3 to itself four times. We don't write it out the long way — we write it as 4 × 3. That's the whole point of multiplication: it's shorthand for repeated addition. Algebra works the same way. x + x + x + x means we add x to itself four times — whatever x turns out to be. So it equals 4 × x.
Arithmetic: 3 + 3 + 3 + 3 = 4 × 3
Algebra: x + x + x + x = 4 × x
2
Apply the convention: drop the × sign
In algebra, when a number multiplies a variable, we leave out the × sign and write them right next to each other. So 4 × x becomes 4x. Why? Because the × symbol looks too much like the letter x — it gets confusing fast. The number in front of the variable has a name: it's called the coefficient, and it tells you how many copies of the variable you have.
4 × x becomes 4x
↑ coefficient ↑ variable
3
Verify with a substitution — they really are the same number
Pick any value for x — say x = 5. Compute both expressions and check.
When x = 5:
x + x + x + x = 5 + 5 + 5 + 5 = 20
4x = 4 × 5 = 20 ✓
Try x = 10: 10+10+10+10 = 40, and 4×10 = 40. ✓ Try any value — they always agree.
Big idea x + x + x + x = 4x — two ways of writing the same expression

6Together — does 3x + 4 equal 3(x + 4)?

These two expressions look almost identical. Just one set of brackets between them. Does that change anything? Let's test it by substituting x = 2 into each, step by step.

💡 The takeaway: in 3x + 4, the 3 only multiplies the x — the +4 is added afterwards. In 3(x + 4), the brackets group x and 4 together, and the 3 multiplies the whole thing. Different operations, different answers. Notation matters. A single set of brackets changes what the expression means.
