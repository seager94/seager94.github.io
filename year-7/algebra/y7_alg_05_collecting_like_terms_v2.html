1Why this matters

A real situation that's secretly today's algebra.

Your school canteen is launching a new smoothie. The price hasn't been decided yet — let's call it x dollars each.

  • On Monday you buy 3 smoothies — that's 3x dollars.
  • On Tuesday you buy 2 more — that's 2x dollars.

How much have you spent in total? You've bought 5 smoothies — so it's 5x dollars. That's true no matter what the price turns out to be.

In algebra: 3x + 2x = 5x. The variable x lets us write the answer even when we don't know the actual number. Today we learn the rules for combining — or collecting — these like terms in any expression.

Terms with the same variable. Constants are like terms with each other.

5Worked example — the 3-step method

Simplify: 4x + 3 + 2x + 5

1
Identify like terms
Colour-code the x-terms and the constants. Same colour = like terms.
4x + 3 + 2x + 5
2
Add the coefficients of each group
For the x-terms, add 4 + 2. For the constants, add 3 + 5. The variable stays the same — we're only counting how many x's we have.
(4 + 2)x + (3 + 5)
= 6x + 8
3
Check by trying a value
Pretend x = 10. The original is 4(10) + 3 + 2(10) + 5 = 40 + 3 + 20 + 5 = 68. The simplified form is 6(10) + 8 = 60 + 8 = 68. ✓ Both give the same answer — that means the simplified version really is equal to the original, no matter what number x stands for.
Both expressions give 68 when x = 10 — the simplification is correct.
Answer 6x + 8
