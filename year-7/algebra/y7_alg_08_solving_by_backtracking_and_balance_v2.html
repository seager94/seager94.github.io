1Why this matters

A real situation that's secretly today's algebra.

A taxi journey costs a flat $4 flag-fall plus $3 per kilometre. Your fare comes to $19.

How far did you travel? You wouldn't guess — you'd work backwards:

  • Start at $19
  • Take off the $4 flag-fall → $15
  • Divide by $3 per km → 5 km
You just solved the equation 3x + 4 = 19 by working backwards. Today we'll learn two ways to undo equations — the function machine (rewind the video) and the balance scale (do the same thing to both sides).

5Worked example — solve 3x + 5 = 14

We'll use the function machine method. Think: "what was done to x to get 14? Now rewind it."

1
Build the function machine — forwards
What's happening to x? First it's multiplied by 3, then 5 is added, and the output is 14.
x → × 3 → + 5 → 14
Forward direction — this matches the equation 3x + 5 = 14.
2
Rewind the machine — apply inverse operations in reverse order
Start at the output (14). The last thing done was "+5", so the first thing to undo is "−5". Then undo the "×3" with "÷3".
3 ← ÷ 3 ← − 5 ← 14
Rewind: 14 − 5 = 9, then 9 ÷ 3 = 3. So x = 3.
3
Verify by substituting
From last lesson — always check by putting your answer back into the original equation.
3x + 5 = 3(3) + 5 = 9 + 5 = 14 ✓
Solution x = 3

How the methods connect

Function machine and balance are the same idea in two pictures. The function machine reminds you which operation to undo first. The balance reminds you to do it to both sides.

Most students prefer the balance method once they're confident — it's the standard way of writing your working in high school.
