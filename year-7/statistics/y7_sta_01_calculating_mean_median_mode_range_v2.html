1Why this matters

A real situation that's secretly today's statistics.

Coach Mara has to pick one striker for Saturday's grand final ⚽. Across the whole season, Jordan and Sam scored exactly the same number of goals — so their goals-per-game average is identical.

But Jordan scores one or two goals almost every week. Sam has quiet games with none… then suddenly nets five. Same average — very different players. Which one should start?

The mean tells Coach Mara the typical score, but it hides how consistent a player is. The range measures that spread. Today you'll calculate all four measures — mean, median, mode and range — and learn what each one reveals about a set of data.

5Worked example 1 — four measures from a list

A soccer team scored these goals across 7 games: 3, 2, 5, 3, 8, 3, 4. Find the mean, median, mode and range.

1
Order the data, then read off the range and mode
Write the values smallest to largest. Once ordered, the range and mode are easy to spot.
Ordered: 2, 3, 3, 3, 4, 5, 8
Range = 8 − 2 = 6
Mode = 3  (it appears three times)
2
Find the median — the middle value
There are 7 values, so the middle one is the 4th.
2, 3, 3, 3, 4, 5, 8  →  Median = 3
3
Find the mean, then compare
Add every value, then divide by how many there are (7). The mean (4) is higher than the median (3): the single large value, 8, pulls the mean upward — the data is slightly skewed to the right.
Mean = (2 + 3 + 3 + 3 + 4 + 5 + 8) ÷ 7 = 28 ÷ 7 = 4
Answer Mean 4 · Median 3 · Mode 3 · Range 6

6Worked example 2 — reading the measures off a dot plot

A dot plot shows every data value as a dot. Here are the goals scored across 10 games. We can read all four measures straight from it.

Goals scored per game — 10 games
Each dot is one game.
1
Read the mode and range from the shape
The mode is the value with the tallest stack of dots. The range is the largest value minus the smallest.
Tallest stack sits above 2  →  Mode = 2
Smallest = 0, largest = 5  →  Range = 5 − 0 = 5
2
Find the median by counting dots
There are 10 dots, so the median is halfway between the 5th and 6th dot, counting from the left.
0, 1, 1, 2, 2, 2, 2, 3, 3, 5  →  5th and 6th are both 2  →  Median = 2
3
Find the mean, then comment on the shape
Multiply each value by how many dots it has, add the results, then divide by 10. The mean (2.1) sits just above the median (2): the lone game with 5 goals stretches the data to the right.
Sum = (0×1) + (1×2) + (2×4) + (3×2) + (5×1) = 0 + 2 + 8 + 6 + 5 = 21
Mean = 21 ÷ 10 = 2.1
Answer Mean 2.1 · Median 2 · Mode 2 · Range 5

7Worked example 3 — same centre, different data

Two different data sets can share the same measures of centre. Compare Set A (4, 5, 6, 7, 8) and Set B (1, 5, 6, 7, 11).

1
Mean and median of Set A
Set A is already in order. Add the values for the mean; the middle value is the median.
Set A: 4, 5, 6, 7, 8
Mean = 30 ÷ 5 = 6  ·  Median = 6
2
Mean and median of Set B
Now do exactly the same for Set B.
Set B: 1, 5, 6, 7, 11
Mean = 30 ÷ 5 = 6  ·  Median = 6
Same mean and median as Set A!
3
Now compare the spread
The centres are identical — but are the data sets the same? Check the range. Measures of centre alone don't describe a data set fully: Set B is far more spread out. This is why we also measure variation, using the range.
Set A range = 8 − 4 = 4
Set B range = 11 − 1 = 10
Big idea Same mean & median — very different spread
