1Why this matters

A measurement that changed mathematics forever.

An architect designs a circular window with a diameter of exactly 1 metre. To order the right length of frame, she wraps a tape measure around the edge and reads 3.14159… metres — exactly π metres.

She tries again with a different circle, same result: the ratio of circumference to diameter is always the same strange number. No matter how carefully she measures, the decimal never stops, never repeats.

This number — and numbers like √2 — belong to a new category: irrational numbers. Today we'll learn what makes them different, and where they live on the number line.

The ratio C ÷ d = π for every circle — a constant that is irrational.

5Worked example 1 — Classifying rational and irrational numbers

Classify each of these numbers as rational or irrational: 0.75,  √9,  √2,  π,  −3

1
Recall the test
A number is rational if it can be written as p/q (integers, q ≠ 0). It is irrational if its decimal is non-terminating AND non-recurring.
Rational: integers, fractions, terminating decimals, recurring decimals.
Irrational: decimal goes on forever with no repeating block. Cannot be p/q.
2
Check each number
Apply the test to each number one at a time.
0.75 = 34 → rational
√9 = 3 = 31 → rational (perfect square)
√2 = 1.41421356… (no repeat) → irrational
π = 3.14159265… (no repeat) → irrational
−3 = −31 → rational
3
Classify and record
Separate into two groups.
Rational: 0.75, √9 (= 3), −3
Irrational: √2, π
Key idea Not all square roots are irrational — only those where the radicand is not a perfect square.

6Worked example 2 — Locating √2 on the number line

Show that 1 < √2 < 2, then narrow it down to 1.4 < √2 < 1.5.

1
Find the consecutive integers
Square the integers on either side until you bracket √2.
1² = 1 < 2 < 4 = 2²
∴ 1 < √2 < 2
2
Narrow to one decimal place
Try 1.4 and 1.5 — square each and check which side of 2 they land.
1.4² = 1.96 < 2 < 2.25 = 1.5²
∴ 1.4 < √2 < 1.5
3
Mark the position on the number line
√2 ≈ 1.414 sits between 1.4 and 1.5, closer to 1.4.
Method Square the boundary values to bracket the irrational. Repeat to get more decimal places.

7Worked example 3 — The string-and-circle demonstration

Three circular objects are measured with string and a ruler. What does C ÷ d always equal?

1
Record the measurements
Wrap string around each object to measure circumference (C); measure diameter (d) directly.
ObjectCircumference CDiameter dC ÷ d
Coin7.85 cm2.5 cm?
Plate94.2 cm30.0 cm?
Tin can23.55 cm7.5 cm?
2
Calculate C ÷ d for each object
Divide circumference by diameter and round to 2 decimal places.
Coin:  7.85 ÷ 2.5 = 3.14
Plate:  94.2 ÷ 30.0 = 3.14
Tin can:  23.55 ÷ 7.5 = 3.14
3
Identify the constant ratio
Every circle gives the same ratio — this universal constant is π.
For any circle: C ÷ d = π = 3.14159265358979…

Exact value: non-terminating, non-recurring → irrational.
3.141 < π < 3.142  (it sits between these two rationals on the number line.)
Key insight C ÷ d = π for every circle — a universal irrational constant. 22/7 ≈ 3.143 is only an approximation.
