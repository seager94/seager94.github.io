1Why this matters

A real situation that secretly contains today's algebra.

A café manager orders supplies each week. Each of the 5 supply cases contains m boxes of coffee pods and 2n boxes of tea bags. The manager also grabs 3 extra boxes of coffee pods for a busy weekend, but returns 4 boxes of tea bags.

The total order is 5(m + 2n) + 3m − 4n. How many of each item does the manager actually receive?

Expanding then simplifying gives the answer:

5(m + 2n) + 3m − 4n
= 5m + 10n + 3m − 4n
= 8m + 6n
8 boxes of coffee pods and 6 boxes of tea bags. Multi-step simplifying combines the distributive and commutative properties to reveal this.

Like Terms

Terms with the same variable part — they can be added or subtracted.
5m and 3m are like terms (both m). 5m and 4n are not — different variables.
Simplify
Tap to flip
To rewrite an expression in its simplest equivalent form — no brackets, no like terms remaining.

Distributive Property
Tap to flip
a(b + c) = ab + ac — the factor distributes across every term inside the bracket.

5Worked examples — the 3-step method

Three examples: expand, collect like terms, then verify by substitution. Work through each one before moving on.

Example A  Simplify 3(x + 4) + 2x

1
Expand the bracket — distributive property
Multiply 3 by every term inside the bracket. Do this before anything else — expanding reveals all the individual terms so like terms become visible.
3(x + 4) + 2x

Distributive property: 3 × x + 3 × 4
= 3x + 12 + 2x

Now all terms are visible — no brackets remain.
2
Group and collect like terms — commutative & associative properties
Use the commutative property to reorder terms so like terms sit together, then the associative property to group and add them.
3x + 12 + 2x

Group x-terms: (3x + 2x) + 12
= 5x + 12
3
Verify by substituting a test value
Substitute x = 2 into both the original expression and the simplified form. If they give the same value, the expressions are equivalent.
Test value: x = 2

Original: 3(2 + 4) + 2 × 2 = 3(6) + 4 = 18 + 4 = 22
Simplified: 5(2) + 12 = 10 + 12 = 22  ✓
Distributive + Commutative + Associative properties 3(x + 4) + 2x = 5x + 12

Example B  Simplify 5(m + 2n) + 3m − 4n

1
Expand the bracket — distributive property
Multiply 5 by both terms inside the bracket. With two variables, be careful to distribute to each term separately.
5(m + 2n) + 3m − 4n

Distributive property: 5 × m + 5 × 2n
= 5m + 10n + 3m − 4n
2
Group like terms by variable — commutative & associative properties
With two variables, group all m-terms together and all n-terms together, then collect each group separately.
5m + 10n + 3m − 4n

m-terms: (5m + 3m) = 8m
n-terms: (10n − 4n) = 6n

Result: 8m + 6n
3
Verify by substituting test values
Substitute m = 1, n = 1 into both forms. Equal results confirm the expressions are equivalent.
Test values: m = 1, n = 1

Original: 5(1 + 2) + 3(1) − 4(1) = 5(3) + 3 − 4 = 15 − 1 = 14
Simplified: 8(1) + 6(1) = 8 + 6 = 14  ✓
Distributive + Commutative + Associative properties 5(m + 2n) + 3m − 4n = 8m + 6n

Example C  Simplify 4(2a − b) + 3a + 5b  — negative term inside the bracket

1
Expand the bracket — distributive property with a negative term
4 distributes to both terms inside. When the term is −b, multiply: 4 × (−b) = −4b. The negative sign belongs to the term.
4(2a − b) + 3a + 5b

Distributive property: 4 × 2a + 4 × (−b)
= 8a − 4b + 3a + 5b
2
Group and collect like terms
Group a-terms and b-terms separately. Note that −4b + 5b = +1b = b (the inverse property at work: the negative partially cancels).
8a − 4b + 3a + 5b

a-terms: (8a + 3a) = 11a
b-terms: (−4b + 5b) = b

Result: 11a + b
3
Verify by substituting test values
Substitute a = 2, b = 1 into both the original and simplified expressions.
Test values: a = 2, b = 1

Original: 4(2×2 − 1) + 3×2 + 5×1 = 4(4−1) + 6 + 5 = 4(3) + 11 = 12 + 11 = 23
Simplified: 11(2) + 1 = 22 + 1 = 23  ✓
Distributive + Inverse + Commutative properties 4(2a − b) + 3a + 5b = 11a + b
