1Why this matters

A real situation that is secretly today's algebra.

A plumber charges a $50 call-out fee plus $80 for each hour of work. Here is what you would pay:

h (hours)0123
C (cost $)50130210290

Each extra hour adds exactly $80. The cost increases by the same amount every time — that pattern is a linear relationship, and its graph is a straight line.

The maths behind it

The rule is C = 80h + 50.

Today we learn how to:
 • complete a table of values from a rule like this
 • spot a linear relationship from a constant first difference
 • plot the ordered pairs on the Cartesian plane and verify the points lie on a straight line

2Key vocabulary

Tap each card to flip and reveal the definition. You'll use all five words today.

Ordered pair
Tap to flip
A pair of numbers (x, y) describing a location on the Cartesian plane. Order matters — first is horizontal, second is vertical.
(3, −2) means 3 right, 2 down from the origin.
Table of values
Tap to flip
A table showing pairs of x and y values that satisfy a rule. Each column is one ordered pair.
For y = 2x + 1: when x = 3, y = 7.
First difference
Tap to flip
The result of subtracting consecutive y-values in a table: y₂ − y₁, y₃ − y₂, and so on.
y: 1, 4, 7, 10 → first differences: +3, +3, +3
Linear relationship
Tap to flip
A relationship where the graph is a straight line. In a table, all first differences are equal.
y = 2x + 1 is linear — its graph is a straight line.
Cartesian plane
Tap to flip
A flat surface with two perpendicular number lines: the horizontal x-axis and the vertical y-axis. They cross at the origin (0, 0).
(−2, 4) is plotted 2 left, 4 up.

3Linear or Not Linear?

Drag each card showing a sequence of first differences into the correct bucket. A constant first difference means the relationship is linear; a changing first difference means it is not.

✔ Linear — constant first difference

✘ Not Linear — changing first difference

💡 Notice the pattern: linear sequences grow by adding the same amount each time. Non-linear sequences grow by different amounts — or by multiplying.

5Worked examples — the 3-step method

For each example: Step 1 — complete the table. Step 2 — check the first difference. Step 3 — plot the ordered pairs and verify they lie on a straight line.

Example 1 of 3
Rule: y = 2x + 1 for x = −2, −1, 0, 1, 2. Complete the table, find the first difference, and plot the ordered pairs.
1
Complete the table of values
Substitute each x-value into y = 2x + 1.
x−2−1012
y 2(−2)+1 = −3 2(−1)+1 = −1 2(0)+1 = 1 2(1)+1 = 3 2(2)+1 = 5
2
Calculate the first differences
Subtract consecutive y-values: y₂ − y₁, y₃ − y₂, …
x−2−1012
y−3−1135
1st diff+2+2+2+2

All first differences equal +2 — constant → the relationship is linear.

3
Plot the ordered pairs and verify a straight line
Plot (−2, −3), (−1, −1), (0, 1), (1, 3), (2, 5). All five points lie on a single straight line. ✓
Conclusion Constant first difference (+2) → linear → all 5 points lie on the line y = 2x + 1. ✓
Example 2 of 3
Rule: y = −x + 3 for x = −1, 0, 1, 2, 3. Complete the table, find the first difference, and plot the ordered pairs.
1
Complete the table of values
Substitute each x-value into y = −x + 3. Remember: −(−1) = +1.
x−10123
y −(−1)+3 = 4 −(0)+3 = 3 −(1)+3 = 2 −(2)+3 = 1 −(3)+3 = 0
2
Calculate the first differences
Subtract consecutive y-values: 3 − 4 = −1, 2 − 3 = −1, …
x−10123
y43210
1st diff−1−1−1−1

All first differences equal −1 — constant → the relationship is linear. The line is decreasing (going downhill left to right).

3
Plot the ordered pairs and verify a straight line
Plot (−1, 4), (0, 3), (1, 2), (2, 1), (3, 0). The points decrease from left to right and all lie on one straight line. ✓
Conclusion Constant first difference (−1) → decreasing linear line → all 5 points lie on y = −x + 3. ✓
Example 3 of 3
A table of values is given below. No rule is shown. Determine whether the relationship is linear, find the rule, and verify one point on a graph.
x0123
y25811
1
Calculate the first differences
Subtract consecutive y-values: 5 − 2 = 3, 8 − 5 = 3, 11 − 8 = 3.
x0123
y25811
1st diff+3+3+3

All first differences equal +3 — constant → the relationship is linear.

2
Find the rule
The constant first difference tells us the coefficient of x. When x = 0, y = 2 tells us the starting value (the y-intercept).
Constant first difference = 3 → coefficient of x is 3.
When x = 0: y = 2 → the y-intercept is 2.

Rule: y = 3x + 2

Verify with another point: when x = 3: y = 3(3) + 2 = 11 ✓
3
Plot the ordered pairs and verify a straight line
Plot (0, 2), (1, 5), (2, 8), (3, 11). The points are collinear — they lie on a single straight line. ✓
Conclusion Constant first difference (+3) → linear → rule is y = 3x + 2 → all 4 points lie on a straight line. ✓
