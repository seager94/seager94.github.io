1Why this matters

A real situation that's secretly today's algebra.

You need a taxi late at night. The driver says:

  • Flag-fall fee: $3.50 just for getting in.
  • Rate: $2.20 for every kilometre travelled.

You want to know the cost before you arrive — so you build a mathematical model. You write one rule that works for any distance, then substitute to get any cost you need.

Let d = distance in km. Then:

Cost = 2.20d + 3.50

The 2.20 is the rate of change (slope) — cost rises $2.20 per km.
The 3.50 is the y-intercept — the starting cost before you even move.

Today you'll build models like this for taxis, water tanks, and trade quotes — and you'll learn to check when a model stops making sense.

Linear model
Tap to flip
A function of the form y = mx + c used to represent a real-world situation.
Taxi cost: C = 2.2d + 3.5 — total cost depends linearly on distance.
Rate of change
Tap to flip
How quickly one quantity changes per unit of another — the slope m in y = mx + c.
$2.20 per km — the cost increases by $2.20 for each extra km.
y-intercept
Tap to flip
The value of y when x = 0 — the starting value c in the model.
The $3.50 flag-fall is paid before any km — it is the y-intercept of the taxi model.
Domain restriction
Tap to flip
The set of input values that are meaningful in the real context — often x ≥ 0.
For a draining tank, t can only go up to the moment it empties — not beyond.
Model validity
Tap to flip
Whether the equation gives a sensible answer for a given input — checking if predictions are physically possible.
A tank model giving −50 L is invalid — you can't have negative water.

5Worked examples — building linear models

Three real contexts. For each: identify the slope and y-intercept, write the rule, substitute to solve, then check validity.

Example A — Taxi fare with flag-fall fee

A taxi charges a $3.50 flag-fall fee plus $2.20 per km. Write a rule for total cost C in dollars after travelling d km. Use it to find the cost for 8 km. State any domain restriction.

1
Identify the slope and y-intercept
The flag-fall is paid before moving — it is the starting value (y-intercept). The per-km rate is the rate of change (slope).
Slope (m) = 2.20  — cost increases $2.20 for each extra km
y-intercept (c) = 3.50  — the fixed flag-fall charge
2
Write the linear model
Substitute m and c into the general form y = mx + c, using context-appropriate variable names.
C = 2.20d + 3.50
When d = 8:   C = 2.20 × 8 + 3.50 = 17.60 + 3.50 = $21.10
3
State the domain restriction and check validity
Distance cannot be negative, so the model is only valid for d ≥ 0. Within that domain, every output is physically meaningful.
Domain: d ≥ 0  (you can travel 0 km — just pay the flag-fall — but not negative km)
If d = −3, the formula gives C = 2.20(−3) + 3.50 = −3.10 — a negative cost makes no sense. The restriction rules this out.
AnswerC = 2.20d + 3.50;  cost for 8 km = $21.10;  valid for d ≥ 0
Example B — Water tank draining over time

A 600 L water tank drains at 30 L per minute. Write a rule for the volume V (litres) after t minutes. Find when the tank is empty. Identify the domain restriction.

1
Identify the slope and y-intercept
The tank starts full — that's the y-intercept. It is draining, so volume decreases: the slope is negative.
Slope (m) = −30  — volume decreases 30 L each minute
y-intercept (c) = 600  — starting volume when t = 0
2
Write the rule and find when the tank empties
Substitute into the general form, then set V = 0 to find the time at which the tank is empty.
V = −30t + 600
Set V = 0:   0 = −30t + 600
30t = 600  ⟹  t = 20 minutes
3
State the domain restriction — review model validity
Once the tank is empty at t = 20, no more water flows. The model should not be used beyond t = 20.
Domain: 0 ≤ t ≤ 20
At t = 25: V = −30(25) + 600 = −150 L — impossible. The model is invalid for t > 20.
⚠️ Model validity: Once the tank empties, the linear model breaks down. Real contexts always have limits — a model that predicts negative water, negative cost, or negative time is signalling it has gone out of range.
AnswerV = −30t + 600;  empty at t = 20 min;  valid for 0 ≤ t ≤ 20
Example C — Plumber's trade quote with call-out fee

A plumber charges a $90 call-out fee plus $75 per hour. Write a rule for total cost C after h hours. Find the cost for 2.5 hours and for 0 hours.

1
Identify the slope and y-intercept
The call-out fee is charged before any work starts — that is the y-intercept. The hourly rate is the slope.
Slope (m) = 75  — cost increases $75 for each hour of work
y-intercept (c) = 90  — the call-out fee charged at h = 0
2
Write the rule and substitute
Build the model, then find the cost for 2.5 hours and for 0 hours (just the call-out).
C = 75h + 90
When h = 2.5:   C = 75(2.5) + 90 = 187.50 + 90 = $277.50
When h = 0:   C = 75(0) + 90 = $90  (the call-out fee alone)
3
Communicate the answer in context
Interpret each value using the correct units and reference the real situation — don't just write a number.
The $90 y-intercept means: even if no work is done, you still pay the call-out.
The $75 slope means: every additional hour adds $75 to the bill.
Domain: h ≥ 0  (you can't work negative hours).
AnswerC = 75h + 90;  2.5 hours costs $277.50;  valid for h ≥ 0
