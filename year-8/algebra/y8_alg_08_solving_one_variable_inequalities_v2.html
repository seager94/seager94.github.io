1Why this matters

A real situation that's secretly today's algebra.

You're organising a class fundraiser. A printing company charges a $25 set-up fee plus $4 per poster. Your budget is less than $65.

How many posters can you order without going over budget?

You need to find every value of p that keeps your total cost under $65 — not just one answer, but a whole range of values. That's an inequality.

The cost rule is 4p + 25 < 65.

Today you will learn to solve inequalities like this using inverse operations, represent the solution on a number line, and check your answer by testing a value.

The solution tells you: p < 10 — any whole number of posters up to 9 is within budget.

5Worked examples — the 3-step method

Every inequality is solved the same way: apply inverse operations to isolate the variable, then represent the solution on a number line and verify with a test value.

Example A — solve 2x + 3 < 11  (form: ax + b < c)
1
Apply inverse operations to isolate x
Undo "+ 3" by subtracting 3 from both sides, then undo "× 2" by dividing both sides by 2. The inequality sign stays the same (we are not dividing by a negative number).
2x + 3 < 11
− 3 on both sides:   2x < 8
÷ 2 on both sides:   x < 4
2
Represent the solution on a number line
Draw an open circle at 4 (4 is NOT included — the inequality is strict). Shade the ray pointing left to show all values less than 4.
3
Verify with a test value
Pick a value IN the solution set and one OUTSIDE it. Both checks should agree with the solution.
Test x = 2 (should satisfy):   2(2) + 3 = 7   7 < 11 ✓
Test x = 5 (should fail):   2(5) + 3 = 13   13 < 11 ✗
Solutionx < 4
Example B — solve 3x − 5 > 7  (form: ax + b > c)
1
Apply inverse operations to isolate x
Undo "− 5" by adding 5 to both sides, then undo "× 3" by dividing both sides by 3.
3x − 5 > 7
+ 5 on both sides:   3x > 12
÷ 3 on both sides:   x > 4
2
Represent the solution on a number line
Open circle at 4 (4 is NOT included). Shade the ray pointing right — all values greater than 4.
3
Verify with a test value
Choose one value inside the solution and one outside.
Test x = 6 (should satisfy):   3(6) − 5 = 13   13 > 7 ✓
Test x = 3 (should fail):   3(3) − 5 = 4   4 > 7 ✗
Solutionx > 4
Example C — solve 4x + 1 < 25 and interpret graphically
1
Solve algebraically using inverse operations
Subtract 1, then divide by 4.
4x + 1 < 25
− 1 on both sides:   4x < 24
÷ 4 on both sides:   x < 6
2
Represent on a number line and verify
Open circle at 6, shade left. Test x = 4: 4(4) + 1 = 17 < 25 ✓. Test x = 7: 4(7) + 1 = 29 < 25 ✗.
3
Interpret the solution graphically
Think of the left-hand side as a line y = 4x + 1. The inequality asks: where is this line BELOW the horizontal line y = 25?
Imagine plotting y = 4x + 1 on the Cartesian plane:
When x < 6:   the line lies below the horizontal line y = 25 ✓
When x > 6:   the line rises above y = 25 ✗
The solution x < 6 is the set of x-values where the line is below y = 25 — the region to the left of x = 6.
Solutionx < 6   —   the line y = 4x + 1 lies below y = 25 for all x < 6
