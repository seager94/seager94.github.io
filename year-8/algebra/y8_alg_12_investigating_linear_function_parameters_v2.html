1Why this matters

A real situation that uses today's algebra.

A solar energy company charges customers based on their daily electricity usage. Their pricing follows a linear model:

Cost = m × units used + c

Changing the rate per unit (m) makes the line steeper or shallower. Changing the daily fixed fee (c) shifts the whole line up or down. Engineers experiment with different values of m and c to model different plans.

In maths, we write this as y = mx + c. Today you will systematically vary m and c, observe the effect on the graph, and form conjectures — statements that you think are always true, which you then test.

2Key vocabulary

Tap each card to flip and reveal the definition. These five words are the language of today's lesson.

Gradient
Tap to flip
The steepness and direction of a line — how much y changes for each 1-unit increase in x.
In y = 3x + 1, the gradient is 3.
y-intercept
Tap to flip
The point where the line crosses the y-axis — i.e. the value of y when x = 0.
In y = 3x + 5, the y-intercept is 5.
Parameter
Tap to flip
A value that controls the shape or position of a function. In y = mx + c, both m and c are parameters.
Change m → the gradient changes. Change c → the intercept shifts.
Conjecture
Tap to flip
A statement you believe to be true based on observed patterns — but that still needs testing or proving.
"When m is negative the line slopes downward" is a conjecture until verified.
Linear function
Tap to flip
A function whose graph is a straight line. Written as y = mx + c where m and c are constants.
y = 2x − 3 is linear. y = x² is not.

5Worked example 1 — the effect of m

Compare y = x + 2, y = 3x + 2, and y = −2x + 2. What does changing m do?

1
Identify — what is the same and what is different?
All three lines have c = 2, so the y-intercept is fixed at 2. Only m changes: 1, 3, and −2.
y = x + 2    m = 1     c = 2
y = 3x + 2   m = 3     c = 2
y = −2x + 2   m = −2   c = 2
2
Observe — build a table of values at x = 0, 1, 2
Compare the y-values in each column to see how quickly they grow or fall.

All three start at the same y-intercept (2), but grow at very different rates.

Generalise — form a conjecture
What pattern emerges from the data?
m = 3 → steeper than m = 1 → steeper than m = −2 (which falls)

A larger positive m gives a steeper upward slope.
A negative m gives a downward slope.
Conjecture 1 In y = mx + c, the parameter m controls both the steepness and the direction of the line. A larger |m| means a steeper line; a negative m means the line slopes downward.

6Worked example 2 — the effect of c

Compare y = 2x − 1, y = 2x + 3, and y = 2x. What does changing c do?

1
Identify — what is the same and what is different?
All three lines have m = 2, so the gradient is fixed. Only c changes: −1, 3, and 0.
m = 2 for all three lines

c = −1    →  y-intercept at (0, −1)
c =  0    →  y-intercept at (0, 0)
c =  3    →  y-intercept at (0, 3)
2
Observe — same gradient, different positions
At each value of x, the y-values differ by exactly the difference in c.
xy = 2x − 1y = 2xy = 2x + 3
0−103
1125
2347

Each column increases by 2 (the gradient). Each row is 1 apart (matching the difference in c).
3
Generalise — form a conjecture about c
These three lines are parallel — they never intersect because they share the same gradient.
Lines with equal gradients are parallel.

Increasing c shifts the line upward (higher y-intercept).
Decreasing c shifts the line downward.
Conjecture 2 In y = mx + c, the parameter c controls where the line crosses the y-axis. Changing c shifts the line up or down without changing its gradient.
