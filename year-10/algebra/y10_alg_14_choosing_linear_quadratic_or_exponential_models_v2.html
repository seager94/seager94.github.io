1Why this matters

A glance at the shape — and a glance at the table — is enough to pick the right model.

A market analyst stares at three columns of numbers — sales, profit, audience size — and has 30 seconds before the meeting starts. Which family of equations should she model each one with?

She doesn't graph them. She looks at how the numbers change between rows.

  • Same amount added each step? Linear.
  • Same amount multiplied each step? Exponential.
  • Differences themselves changing by a constant? Quadratic.

That table-based diagnostic is today's whole lesson. Once you can spot it, you can give the right model the right job — savings growth, falling objects, compound interest, viral spread, projectile motion.

All three curves start at the same value — the diagnostic comes from how fast they pull apart.

Exponential model

5Worked example — Mia's savings

Mia opens a savings account. After x weeks she has y dollars: (0, 80), (1, 95), (2, 110), (3, 125), (4, 140). Which model fits — and what's the rule?

1
Run the diagnostic on first differences
Subtract each y from the one after it.
x01234
y8095110125140
1st diff+15+15+15+15
All four first differences are +15 — constant.
2
Name the family and write the rule
Constant first difference ⇒ linear. The first difference is the slope (m); the value at x = 0 is the intercept (c).
m = 15 (rises $15 per week), c = 80 (starting balance)
⟹ y = 15x + 80
3
Check the rule against one further data point
Try x = 4 — we should get 140.
y = 15(4) + 80 = 60 + 80 = 140 ✓
And one beyond the table — predict x = 10: y = 15(10) + 80 = 230. After 10 weeks Mia will have $230.
Linear model — answer y = 15x + 80
Linear
Constant first difference. Rule: y = mx + c
Quadratic
Constant second difference. Rule: y = ax² + bx + c
Exponential
Constant ratio. Rule: y = a · bx

6Hinge check 🎯 Pick one

A community garden tracks plant height in cm each week. Which model best fits this table?

x (week)01234
y (cm)261854162
Watch out — you've read a ratio as a difference. The first differences are +4, +12, +36, +108 — they are not constant, so it isn't linear. What stays constant is the ratio: 6 ÷ 2 = 3, 18 ÷ 6 = 3, 54 ÷ 18 = 3. Constant ratio ⇒ exponential.
You stopped at first differences. First differences (+4, +12, +36, +108) aren't constant — fair enough to keep going. But check second differences (+8, +24, +72) — those aren't constant either. Try ratios next: each is ×3. Constant ratio ⇒ exponential.
Correct. Each y-value is 3× the previous one — a constant ratio means the family is exponential. The rule is y = 2 · 3x, and a quick check at x = 4 gives 2 · 81 = 162 ✓.
One of A/B/C does fit. Run the three tests in order — first difference, then ratio, then second difference. Here the ratio is constant at ×3, so it's exponential, rule y = 2 · 3x.
