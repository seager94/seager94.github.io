1Why this matters

A real situation that's secretly today's algebra.

You put $1000 into a savings account paying 5% interest per year. After x years, the balance is:

y = 1000 × 1.05x

  • After 1 year: $1050
  • After 14 years: ≈ $1980 (nearly double)
  • After 28 years: ≈ $3920 (nearly quadruple)

Each year the balance grows by a fixed fraction, not a fixed amount — that's what makes the curve steepen.

That curve is an exponential function. Every basic exponential shares the same skeleton: it passes through (0, 1) and hugs the line y = 0 on one side. Today we learn to read its key features straight from the equation — and to predict how translations slide that skeleton up, down, left or right.

2Key vocabulary

Tap each card to flip and reveal the definition. You'll use these five words constantly today.

Exponential function
Tap to flip
A function where the variable sits in the exponent: y = ax with a > 0, a ≠ 1.
y = 2x and y = (13)x are both exponential.
Base
Tap to flip
The number being raised to a power — the a in ax.
In y = 2x: the base is 2 → growth. In y = (12)x: the base is 12 → decay.
Horizontal asymptote
Tap to flip
A horizontal line the graph approaches but never crosses.
For y = ax: the asymptote is y = 0 (the x-axis).
y-intercept
Tap to flip
The y-value where the graph crosses the y-axis (sub x = 0).
For y = ax: a0 = 1, so the y-intercept is always (0, 1).
Growth & decay
Tap to flip
Growth: the graph rises as x increases (when a > 1).
Decay: it falls as x increases (when 0 < a < 1).
y = 3x grows; y = (13)x decays.

💡 The "sometimes" claims depend on the value of k (or the base a): the graph passes through (0, 1) and has range y > 0 only when k = 0. Once you shift the curve up or down, both move with it.

5Worked examples — the skeleton and its shifts

First we read every feature off y = 2x — the skeleton. Then we watch what changes when we translate it.

Example 1 y = 2x The base case — our skeleton
1
Y-intercept — substitute x = 0
Any non-zero number to the power 0 is 1.
20 = 1  ⟹  y-intercept at (0, 1)
2
Horizontal asymptote
As x → −∞, the curve hugs (but never touches) a horizontal line.
2−10 ≈ 0.000977,   2−20 ≈ 0.00000095 ⟹ y → 0
3
Domain, range, behaviour
Read the curve's reach in both directions.
Domain: all real x  |  Range: y > 0  |  Growth (base 2 > 1)
Skeleton features (0, 1)  ·  asymptote y = 0  ·  y > 0  ·  growth
Example 2 y = 2x + 3 Vertical shift up by 3
Y-intercept
(0, 4)   — from 20 + 3 = 1 + 3
Horizontal asymptote
y = 3
Domain
all real x
Range
y > 3
Behaviour
Growth (base 2)
Compare with the skeleton: every point of y = 2x has moved up 3. The asymptote slid from y = 0 to y = 3, and the y-intercept slid from 1 to 4. The shape is identical.
Example 3 y = 2x−1 Horizontal shift right by 1
Y-intercept
(0, ½)   — from 20−1 = 2−1 = ½
Horizontal asymptote
y = 0 (unchanged)
Domain
all real x
Range
y > 0 (unchanged)
Behaviour
Growth (base 2)
Compare with the skeleton: every point of y = 2x has slid right by 1. The skeleton's "(0, 1)" anchor moves to (1, 1) — and the new y-intercept (where x = 0) is now half as high. The asymptote and range don't move because we haven't shifted vertically.
Example 4 y = (12)x Decay — base less than 1
Y-intercept
(0, 1)   — (½)0 = 1
Horizontal asymptote
y = 0
Domain
all real x
Range
y > 0
Behaviour
Decay — falling as x increases (base ½ < 1)
Compare with the skeleton: same y-intercept (0, 1) and same asymptote y = 0, but the curve has been reflected in the y-axis. Hint: (½)x = 2−x.
Stretch synthesis — Compared with the skeleton y = ax, the family y = ax + k differs in three predictable ways:
  • Y-intercept rises (or falls) from (0, 1) to (0, 1 + k).
  • Horizontal asymptote slides from y = 0 to y = k.
  • Range changes from y > 0 to y > k.
Domain stays "all real x" — translations can never change that.
