1Why this matters

A real situation that's secretly today's algebra.

You're running a Year 10 fundraiser. Chocolate bars sell for $2 each and lolly bags for $3 each. To break even you need to take more than $24.

If x is bars sold and y is bags sold, you need 2x + 3y > 24. Every combination of x and y that works fills a whole region of the plane — not just a single point or a single line.

Today we learn to draw that region. The recipe is short: sketch the boundary line, pick a test point such as the origin, and shade the side that makes the inequality true. The boundary style — solid or dashed — records whether the line itself counts.

2Key vocabulary

Tap each card to flip and reveal the definition. You'll use these five words constantly today.

Boundary line
Tap to flip
The straight line you get by replacing the inequality with an equals sign.
For 2x + 3y < 24 the boundary is 2x + 3y = 24.
Half-plane
Tap to flip
A line cuts the plane into two halves. The solution to a linear inequality is always one of those halves.
The line x + y = 6 splits the plane in two — we shade the half that fits.
Test point
Tap to flip
A convenient point picked off the boundary to decide which half to shade. (0, 0) is the favourite — easy arithmetic.
Test (0, 0) in y > 2x − 1: 0 > −1 is true.
Strict inequality
Tap to flip
Uses < or >. The boundary itself is not part of the region — draw it dashed.
y > 2x + 1 → dashed line.
Non-strict inequality
Tap to flip
Uses ≤ or ≥. The boundary is part of the region — draw it solid.
x + y ≤ 6 → solid line.

5Worked example — graph 2x + 3y < 24

Three moves: boundary → style → test point. Watch each step before I reveal the next.

1
Draw the boundary line
Swap < for = and sketch 2x + 3y = 24. The fastest way is the two intercepts.
x-intercept: set y = 0 → 2x = 24 → (12, 0)
y-intercept: set x = 0 → 3y = 24 → (0, 8)
2
Decide the boundary style
The symbol is < — strict, so the line itself is not part of the solution. Draw the boundary dashed.
Symbol: <  ⟶  dashed line through (12, 0) and (0, 8).
3
Test the origin and shade
Substitute (0, 0) into the original inequality. If it makes it true, shade the side that contains the origin; if false, shade the other side.
2(0) + 3(0) = 0  and  0 < 24 ✓  true at (0, 0).
So shade the half-plane that contains (0, 0) — the side below the line.
Answer Dashed line through (0, 8) and (12, 0); shade the half-plane below — containing (0, 0).

Second example — same routine, faster: graph x + y ≤ 6.

✓
Boundary, style, test
Boundary: x + y = 6  → intercepts (6, 0) and (0, 6).
Symbol ≤ → solid line.
Test (0, 0): 0 + 0 = 0, and 0 ≤ 6 ✓ true → shade the side containing the origin (below the line).
Answer Solid line through (0, 6) and (6, 0); shade below — origin side.

7Hinge question — read this graph 🎯 Pick one

Look carefully at both the boundary style and the shaded half. Each option matches a specific convention error — pick the one you think is right.

The boundary line is y = x + 2. Which inequality is shown?
Correct. The boundary is dashed, so the line is excluded → strict inequality (> or <). The shaded half is above the line, where y is bigger than x + 2 → choose >. Verify with (0, 0): 0 > 2 is false, and (0, 0) is not shaded — consistent. ✓
You missed the dashed boundary. ≥ would mean the line is part of the region — but it's drawn dashed, which says the line is excluded. The shading direction is right; the symbol is too inclusive. Use >, not ≥.
You flipped the shading. < would mean the shaded half is the one where y is smaller than x + 2 — that's below the line, not above. Sanity check: at (0, 0) the inequality y < x + 2 gives 0 < 2 ✓ — so (0, 0) would be shaded. But on the diagram (0, 0) is not shaded. Flip to >.
Two convention errors at once. ≤ is wrong on both counts: the line is dashed (so it can't be ≤ or ≥), and the shaded half is above the line (so it can't be < or ≤). Re-read the graph piece by piece: dashed → strict; above → bigger; therefore >.

10Practice — Mastery ●●●Mastery

4 questions ▶

The test-point idea reaches further than you think. The boundary doesn't have to be linear — any curve still cuts the plane in two, and (0, 0) still works as a test for many shapes. Try these.

💡 Worked extension. Does the point (3, 5) satisfy 2y < x²? Substitute: 2(5) = 10 and (3)² = 9. Is 10 < 9? No. So (3, 5) does not lie in the region 2y < x² — the same test-point routine still decides it, even though the boundary is now a parabola, not a line.
