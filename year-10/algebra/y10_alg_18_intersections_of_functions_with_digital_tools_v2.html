1Why this matters

Some equations refuse to budge with algebra. Here's how we still answer them.

Consider the equation x2 = 2x. Two functions, set equal. No matter how hard you try, no amount of factorising, rearranging, taking roots or applying the quadratic formula will isolate x exactly for every solution.

But the graph tells the truth straight away. Plot both curves. Where they cross, the two sides agree — and the x-coordinate of each crossing is a solution.

For some crossings you'll then find an exact value by algebra. For others — and there are plenty of others — there is no closed-form answer, so we trap the crossing inside an interval and shrink it: each zoom narrows the window. This is exactly the logic a calculator or graphing app uses behind the scenes.

Three crossings of y = x2 and y = 2x: two land on whole numbers, one does not.
💡 Look closely: at x = 2 and x = 4 the two sides agree exactly (4 = 4 and 16 = 16). The third crossing near x ≈ −0.77 has no clean closed form — we'll find it today by trapping it in an interval and shrinking the interval.

Bisection
Tap to flip
Repeatedly halving the interval — testing the midpoint and keeping the half that still traps the crossing.
Each bisection halves the gap. After 10 bisections it's 1/1024 of the original.

5Worked example — trap the third crossing

From the graph in Section 1, x2 = 2x has a crossing somewhere in the interval (−1, 0). Find an interval of width 0.25 that traps it.

1
Test the endpoints — confirm a crossing is trapped
At each end, work out which side is bigger.
At x = −1: x2 = 1, 2x = 0.5 → x2 > 2x
At x = 0: x2 = 0, 2x = 1 → x2 < 2x
The two sides swap order across (−1, 0), so a crossing is trapped inside.
2
Bisect — test the midpoint and keep the half with the swap
Midpoint of (−1, 0) is x = −0.5.
At x = −0.5: x2 = 0.25, 2x ≈ 0.707 → x2 < 2x
Same order as the right endpoint, so the crossing is in the left half: (−1, −0.5).
3
Bisect again — narrow to width 0.25
Midpoint of (−1, −0.5) is x = −0.75.
At x = −0.75: x2 = 0.5625, 2x ≈ 0.595 → x2 < 2x
Same order as the right end again, so the crossing is in (−1, −0.75).
Interval after 2 bisections x lies in (−1, −0.75) — width 0.25
